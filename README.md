# ENKI Signal — Public showcase

Commercial landing and interactive **static** demonstration for Vyntrava Technologies.

- **Case 1:** Celavie Top Deportivo — five observed variants and quantities 1, 2, 3. Visible ARS 13,000 unit price and stock according to developer's 2026-10-24 execution report.
- **Case 2:** IdentiBasics — remeras and buzos at quantities 3, 5, 10. All prices are indicative **«Desde»**; no confirmed stock or final quote.
- **Data provenance:** `demo-data.json` contains 21 curated records reconstructed from the author's communicated run summary. It is *not* the original RAW evidence, a live API, or an independently audited source.
- The page makes **no requests to the retailers**; it contains no automated scraping, credentials, remote scripts or trackers.
- No commercial relationship with the referenced retailers is implied.
- Product code, raw HTML evidence and the operational scraper are **not** published in this branch.

## Enable Pages

GitHub repository → **Settings → Pages → Build and deployment → Deploy from a branch → gh-pages → /(root) → Save**.

Once published, visit https://johanseb15.github.io/scraper_enki/ .

## About the project

Enki is a price-intelligence development with traceable evidence and explicit uncertainty. The production scraper and adapters require source-specific compliance, deployment and acceptance tests. Do not mistake these interactive reference scenarios for a live scraper.
